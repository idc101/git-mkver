# Development

## Prerequisites

- [Rust](https://www.rust-lang.org/) (cargo, rustc)

## Building

```bash
cargo build
```

## Running Tests

```bash
cargo test
```

## Building Release Binaries

The project includes build scripts for each platform:
- Linux: `./build-linux.sh`
- macOS: `./build-macos.sh`
- Windows: `.\build-windows.ps1`
